05 — Quick Start

Run the MVP in 5 minutes

1
Clone the repository
git clone https://github.com/your-username/ai-resume-builder
Create a new GitHub repo and push the project files.
2
Install dependencies
pip install -r requirements.txt
Installs: streamlit, requests, scikit-learn, numpy
3
Get your FREE HuggingFace token
Go to huggingface.co/settings/tokens → New Token (Read) → Copy it.
Add to .streamlit/secrets.toml: HF_TOKEN = "hf_..."
4
Run the app
streamlit run app.py
Opens at http://localhost:8501
5
Deploy to Streamlit Cloud (free)
Push to GitHub → share.streamlit.io → Connect repo → Add HF_TOKEN in Secrets.
Your app is live with a public URL in ~2 minutes.
6
Optional: Run on Google Colab
!pip install streamlit requests scikit-learn pyngrok
Use pyngrok tunnel to expose Streamlit from Colab: !streamlit run app.py &
